# Derived Outputs

This directory contains small derived research artifacts generated by the notebooks.

Raw NOAA MRMS, NOAA hail, and ERA5 files are not stored here. See `data/README.md` for local data requirements.

The main public outputs are stored under:

```text
outputs/tables/
```

These files are intended to make the principal intermediate checks and modeling results inspectable without requiring a reader to rerun the full raw-data pipeline.

## Notebook 03 — Storm-first sample construction

Notebook 03 establishes the retrospective storm-first sample frame.

Its outputs document:

- radar-coverage eligibility;
- storm-positive and storm-negative grid cells;
- NOAA hail overlay;
- the \(S/H\) contingency structure;
- hail-capture diagnostics;
- storm-conditioned samples;
- matched-control diagnostics.

The key scientific distinction is between:

```text
S=1, H=1   hail-producing storm
S=1, H=0   storm without matched hail
S=0, H=1   hail not captured by storm proxy
S=0, H=0   neither storm nor hail
```

For the three primary retrospective periods, the final strict construction produced:

```text
504 total grid-hours
169 coverage-eligible grid-hours
123 storm-positive grid-hours

S=1, H=1 : 13
S=1, H=0 : 110
S=0, H=1 : 0
S=0, H=0 : 46
```

Notebook 03 should be treated as sample-frame construction rather than as the final predictive experiment.

## Notebook 04 — Retrospective conditioning diagnostic

Notebook 04 evaluates whether conditioning on storm occurrence improves retrospective ERA5-only hail modeling.

Its outputs include:

- direct-versus-conditioned model metrics;
- compact-feature sensitivity analysis;
- random-negative placebo experiments;
- storm-versus-background negative-pool comparisons;
- calibration and probability-score diagnostics.

The result is intentionally mixed.

ERA5-only conditioning does not show a robust universal advantage across the sensitivity analyses.

This notebook is therefore an important negative/mixed diagnostic rather than a failed experiment: it motivates the temporally aligned future-target design used in Notebook 05.

### Period-cluster bootstrap

```text
period_cluster_bootstrap_summary.csv
```

Summarizes period-level bootstrap sensitivity of Hierarchical-minus-Direct metric differences.

The bootstrap resamples development periods rather than individual grid rows.

It measures sensitivity to the composition of the nine development periods.

It is **not** interpreted as:

- a formal hypothesis test;
- a population confidence interval;
- or climatological uncertainty.

## Interpretation boundaries

The outputs in this directory should be interpreted together with the notebook methodology and limitations.

In particular:

- the final Notebook 05 panel contains nine event-enriched periods;
- only 17 radar-coverage-eligible hail-positive cells are available;
- eight additional hail-positive cells were excluded because of inadequate radar coverage;
- leave-one-period-out validation is by period rather than by a large set of independent storm events;
- ERA5 predictors are retrospective reanalysis fields;
- the current analysis is not a climatological population validation.

The next major scientific step is evaluation on a broad hail-independent representative panel.
